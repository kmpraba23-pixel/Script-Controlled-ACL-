### Phase 2
Create the custom roles:
- bb1
- bb2
- bb3
- bb4

### Phase 3
Create the `u_institution_details` custom table and required fields.

### Phase 4
Configure the READ ACL using the bb1 role and Branch field condition.

### Phase 6
