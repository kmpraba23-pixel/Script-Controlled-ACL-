Script-Controlled ACL – Restrict Record Access Based on Field Value
Project Overview

This project implements a Script-Controlled Access Control List system in ServiceNow to restrict access to institution records based on user roles and the Branch field.

Objective

The main objective is to provide secure and controlled access to institution records while allowing administrators to retain complete access.
